# SFI Course B — Bashayer reference

This folder contains a normalized reference profile for **Kommunal vuxenutbildning i svenska för invandrare (SFI), Course B**.

## Source basis

Official Skolverket SFI curriculum and course criteria.

- Course: B
- Possible study paths: Studieväg 1 or Studieväg 2
- Course criteria are the same regardless of study path.
- The actual study path is intentionally left unresolved until confirmed by the school.
- Runtime tutoring material should distinguish official curriculum targets from tutor-created exercises.

## Teaching accommodation

Bashayer's tutoring profile is intentionally expressed in terms of learning accommodations only, not diagnosis or medical details.

Recommended tutoring behavior:
- short sessions
- low instruction density
- one task at a time
- high repetition
- flexible pace
- frequent comprehension checks
- simple, concrete language
- easy pause/resume points

These accommodations change **how** material is taught, not the official SFI B learning targets.
